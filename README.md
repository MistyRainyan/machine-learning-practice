# Week 01：从数据到预测——完整机器学习流程实践

## 1. 实验目的

本实验以经典 Iris 鸢尾花分类任务为例，完成一个机器学习分类任务从数据加载到模型评价的完整流程。

通过实验理解以下机器学习基本概念：

- 特征（Features）
- 标签（Label）
- 训练集（Training Set）
- 测试集（Test Set）
- 模型训练（Fit）
- 模型预测（Predict）
- 模型评价（Evaluation）

## 2. 数据集

实验使用 scikit-learn 内置的 Iris 数据集。

数据集包含 150 个鸢尾花样本，共分为三个类别：

- Setosa
- Versicolor
- Virginica

每个样本包含四个特征：

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

实验任务是根据这四个特征预测鸢尾花所属的类别。

## 3. 实验流程

本实验按照以下流程完成：

1. 加载 Iris 数据集
2. 使用 Pandas 查看和分析数据
3. 对数据进行可视化
4. 将数据划分为训练集和测试集
5. 使用 Logistic Regression 训练分类模型
6. 使用测试集进行预测
7. 使用 Accuracy、混淆矩阵和分类报告评价模型
8. 分析模型的分类结果

## 4. 数据集划分

Iris 数据集共有 150 个样本。

按照 80% : 20% 的比例划分：

- 训练集：120 个样本
- 测试集：30 个样本

同时采用分层抽样，使三个类别在训练集和测试集中保持合理的类别比例。

## 5. 实验结果

模型在测试集上的分类准确率为：

**Accuracy = 96.67%**

30 个测试样本中：

- 正确分类：29 个
- 错误分类：1 个

混淆矩阵为：

| 真实类别 / 预测类别 | Setosa | Versicolor | Virginica |
| --- | ---: | ---: | ---: |
| Setosa | 10 | 0 | 0 |
| Versicolor | 0 | 9 | 1 |
| Virginica | 0 | 0 | 10 |

可以看到：

- Setosa 的 10 个样本全部分类正确；
- Versicolor 中 9 个分类正确，1 个被预测为 Virginica；
- Virginica 的 10 个样本全部分类正确。

唯一的分类错误发生在 Versicolor 和 Virginica 之间。

## 6. 分类评价

分类报告的主要结果如下：

| 类别 | Precision | Recall | F1-score |
| --- | ---: | ---: | ---: |
| Setosa | 1.00 | 1.00 | 1.00 |
| Versicolor | 1.00 | 0.90 | 0.95 |
| Virginica | 0.91 | 1.00 | 0.95 |

模型整体 Accuracy 约为 0.97。

实验结果表明，Iris 数据集中的四个特征能够较好地区分三种鸢尾花，其中 Setosa 的特征差异较为明显，而 Versicolor 和 Virginica 之间存在一定程度的特征重叠。

## 7. 实验总结

通过本次实验，完成了从数据加载、数据探索、数据可视化，到训练集与测试集划分、模型训练、预测和评价的完整机器学习流程。

本实验重点是建立对机器学习工作流程的整体认识，因此暂时将 Logistic Regression 作为分类模型使用，而不深入讨论其数学原理。后续实验将进一步学习和实现具体的机器学习算法。

# Week 02：KNN 分类算法从零实现——基于理化特征的葡萄酒分类

## 实验内容

本实验使用 Wine 葡萄酒数据集，从零实现 K 近邻（KNN）分类算法。

实验主要包括：

- 手写欧氏距离计算；
- 实现最近邻搜索和多数投票；
- 从零实现 KNN 分类器；
- 对比标准化前后的分类效果；
- 研究不同 K 值对分类准确率的影响；
- 使用 sklearn KNeighborsClassifier 验证手写实现。

## 数据集

实验使用 scikit-learn 内置的 Wine 数据集，共包含：

- 178 个样本；
- 13 个理化特征；
- 3 个葡萄酒类别。

按照 80% : 20% 划分训练集和测试集，测试集包含 36 个样本。

## 实验结果

在 K=3 时：

| 数据处理方式 | Accuracy |
| --- | ---: |
| 原始数据 | 75.00% |
| 标准化数据 | 97.22% |

标准化使准确率提高了 **22.22 个百分点**，说明 KNN 对不同特征的数据尺度较为敏感。

进一步测试 K=1～20 后，K=7 是首次达到最高测试准确率的取值：

**Accuracy = 100.00%**

此时 36 个测试样本全部分类正确：

| 真实类别 / 预测类别 | class_0 | class_1 | class_2 |
| --- | ---: | ---: | ---: |
| class_0 | 12 | 0 | 0 |
| class_1 | 0 | 14 | 0 |
| class_2 | 0 | 0 | 10 |

使用相同的数据和参数进行 sklearn 对比实验：

| 实现方式 | Accuracy |
| --- | ---: |
| 手写 KNN | 100.00% |
| sklearn KNN | 100.00% |

两种方法的预测结果完全一致。

## 实验结论

本实验从零实现了 KNN 分类算法，并验证了欧氏距离、最近邻搜索和多数投票等核心步骤。

实验结果表明，特征尺度会明显影响 KNN 的距离计算。在 Wine 数据集上进行标准化后，K=3 时的测试准确率由 75.00% 提高至 97.22%。

不同 K 值也会影响模型的分类结果。本次数据划分下多个 K 值取得了 100% 的测试准确率，其中 K=7 是首次达到最高准确率的取值。

> 完整代码、运行结果、K-Accuracy 曲线、混淆矩阵及详细分析见 `02_knn/experiment.ipynb`。

# Week 03：朴素贝叶斯文本分类

## 实验题目

**朴素贝叶斯文本分类——垃圾短信识别**

## 数据集

实验使用 **SMS Spam Collection** 数据集进行垃圾短信分类。

数据集共包含 **5572 条短信**：

| 类别 | 含义 | 样本数量 |
| --- | --- | ---: |
| ham | 正常短信 | 4825 |
| spam | 垃圾短信 | 747 |

数据集中正常短信数量明显多于垃圾短信，因此除了 Accuracy 外，本实验还结合 Precision、Recall、F1-score 和混淆矩阵评价模型性能。

## 实验内容

本实验主要完成：

1. 使用 `CountVectorizer` 将短信文本转换为词频向量；
2. 分析正常短信与垃圾短信中的词频特征；
3. 从零实现多项式朴素贝叶斯分类算法；
4. 计算类别先验概率；
5. 统计不同类别中的单词条件概率；
6. 分析朴素贝叶斯中的零概率问题；
7. 使用拉普拉斯平滑解决零概率问题；
8. 使用对数概率避免大量小概率相乘产生数值下溢；
9. 使用测试集评价手写朴素贝叶斯模型；
10. 与 sklearn `MultinomialNB` 进行对比。

## 文本特征提取

原始短信文本无法直接用于机器学习模型，因此实验使用词袋模型将文本转换为词频特征。

例如，假设词汇表为：

```text
["free", "win", "meeting"]
```

短信：

```text
free free win
```

可以表示为：

```text
[2, 1, 0]
```

表示 `free` 出现 2 次、`win` 出现 1 次、`meeting` 没有出现。

本实验使用 `CountVectorizer` 建立词汇表，训练集最终得到 **7668 个词特征**。

## 类别先验概率

训练集共有 4457 条短信，其中：

```text
ham：3859
spam：598
```

计算得到：

```text
P(ham)  = 0.8658
P(spam) = 0.1342
```

可以看出，在没有观察短信具体内容之前，一条短信属于正常短信的先验概率明显更高。

## 高频词分析

垃圾短信中出现次数较多的词包括：

```text
to
call
you
your
free
for
the
now
txt
ur
have
stop
text
claim
mobile
```

其中 `free`、`call`、`txt`、`claim`、`mobile` 等词具有较明显的垃圾短信特征。

正常短信中出现次数较多的词包括：

```text
you
to
the
in
and
my
me
is
it
that
of
for
so
have
but
can
are
your
on
not
```

同时可以发现，单纯出现频率较高并不意味着一个词一定具有较强的分类能力。例如 `you`、`to` 等词在两个类别中都较常见，因此朴素贝叶斯实际需要考虑单词在不同类别下的条件概率。

## 零概率问题与拉普拉斯平滑

实验发现：

```text
只在 spam 中出现的词：1621
只在 ham 中出现的词：5126
```

例如单词：

```text
00
```

在两个类别中的词频为：

```text
ham：0
spam：10
```

如果不进行平滑：

```text
P(00 | ham) = 0
```

一个条件概率为 0 可能导致朴素贝叶斯中的整个概率乘积变为 0，从而产生零概率问题。

加入拉普拉斯平滑后：

```text
P(00 | ham) = 1.739856635813209e-05
```

概率由 0 变为一个很小但非零的数值。

这一实验直观验证了拉普拉斯平滑能够有效缓解训练数据中未出现的“类别-特征”组合导致的零概率问题。

## 手写朴素贝叶斯实验结果

手写 Multinomial Naive Bayes 在测试集上的准确率为：

```text
Accuracy：98.74%
```

混淆矩阵：

| 真实类别 | 预测 ham | 预测 spam |
| --- | ---: | ---: |
| ham | 964 | 2 |
| spam | 12 | 137 |

分类报告：

| 类别 | Precision | Recall | F1-score | Support |
| --- | ---: | ---: | ---: | ---: |
| ham | 0.9877 | 0.9979 | 0.9928 | 966 |
| spam | 0.9856 | 0.9195 | 0.9514 | 149 |

模型仅将 **2 条正常短信错误识别为垃圾短信**，同时有 **12 条垃圾短信被错误识别为正常短信**。

虽然总体 Accuracy 达到了 98.74%，但由于数据集存在类别不平衡，因此还需要关注 spam 类别的 Recall。实验中 spam 的 Recall 为 0.9195，说明仍有少量垃圾短信未能被模型识别。

## 与 sklearn MultinomialNB 对比

使用相同的数据划分、词频特征和拉普拉斯平滑参数 `alpha=1.0`，进一步使用 sklearn `MultinomialNB` 进行实验。

结果如下：

| 模型 | Accuracy |
| --- | ---: |
| 手写 Multinomial Naive Bayes | 98.74% |
| sklearn MultinomialNB | 98.74% |

测试集预测结果比较：

```text
两种方法预测结果是否完全一致：True
```

在当前实验设置下，手写朴素贝叶斯与 sklearn `MultinomialNB` 的预测结果完全一致，验证了手写实现中先验概率计算、条件概率计算、拉普拉斯平滑以及对数概率分类过程的正确性。

## Week 03 实验总结

通过本次实验完成了从原始文本到垃圾短信分类的完整机器学习流程，并从零实现了多项式朴素贝叶斯算法。

本次实验主要掌握了：
