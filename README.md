# Week 01：从数据到预测——完整机器学习流程实践

## 1. 实验目的

本实验以经典 Iris 鸢尾花分类任务为例，完成一个机器学习分类任务从数据加载到模型评价的完整流程。

通过实验理解以下机器学习基本概念：

- 特征（Features）
- 标签（Label）
- 训练集（Training Set）
- 测试集（Test Set）
- 模型训练（Fit）
- 模型预测（Predict）
- 模型评价（Evaluation）

## 2. 数据集

实验使用 scikit-learn 内置的 Iris 数据集。

数据集包含 150 个鸢尾花样本，共分为三个类别：

- Setosa
- Versicolor
- Virginica

每个样本包含四个特征：

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

实验任务是根据这四个特征预测鸢尾花所属的类别。

## 3. 实验流程

本实验按照以下流程完成：

1. 加载 Iris 数据集
2. 使用 Pandas 查看和分析数据
3. 对数据进行可视化
4. 将数据划分为训练集和测试集
5. 使用 Logistic Regression 训练分类模型
6. 使用测试集进行预测
7. 使用 Accuracy、混淆矩阵和分类报告评价模型
8. 分析模型的分类结果

## 4. 数据集划分

Iris 数据集共有 150 个样本。

按照 80% : 20% 的比例划分：

- 训练集：120 个样本
- 测试集：30 个样本

同时采用分层抽样，使三个类别在训练集和测试集中保持合理的类别比例。

## 5. 实验结果

模型在测试集上的分类准确率为：

**Accuracy = 96.67%**

30 个测试样本中：

- 正确分类：29 个
- 错误分类：1 个

混淆矩阵为：

| 真实类别 / 预测类别 | Setosa | Versicolor | Virginica |
| --- | ---: | ---: | ---: |
| Setosa | 10 | 0 | 0 |
| Versicolor | 0 | 9 | 1 |
| Virginica | 0 | 0 | 10 |

可以看到：

- Setosa 的 10 个样本全部分类正确；
- Versicolor 中 9 个分类正确，1 个被预测为 Virginica；
- Virginica 的 10 个样本全部分类正确。

唯一的分类错误发生在 Versicolor 和 Virginica 之间。

## 6. 分类评价

分类报告的主要结果如下：

| 类别 | Precision | Recall | F1-score |
| --- | ---: | ---: | ---: |
| Setosa | 1.00 | 1.00 | 1.00 |
| Versicolor | 1.00 | 0.90 | 0.95 |
| Virginica | 0.91 | 1.00 | 0.95 |

模型整体 Accuracy 约为 0.97。

实验结果表明，Iris 数据集中的四个特征能够较好地区分三种鸢尾花，其中 Setosa 的特征差异较为明显，而 Versicolor 和 Virginica 之间存在一定程度的特征重叠。

## 7. 实验总结

通过本次实验，完成了从数据加载、数据探索、数据可视化，到训练集与测试集划分、模型训练、预测和评价的完整机器学习流程。

本实验重点是建立对机器学习工作流程的整体认识，因此暂时将 Logistic Regression 作为分类模型使用，而不深入讨论其数学原理。后续实验将进一步学习和实现具体的机器学习算法。

# Week 02：KNN 分类算法从零实现——基于理化特征的葡萄酒分类

## 实验内容

本实验使用 Wine 葡萄酒数据集，从零实现 K 近邻（KNN）分类算法。

实验主要包括：

- 手写欧氏距离计算；
- 实现最近邻搜索和多数投票；
- 从零实现 KNN 分类器；
- 对比标准化前后的分类效果；
- 研究不同 K 值对分类准确率的影响；
- 使用 sklearn KNeighborsClassifier 验证手写实现。

## 数据集

实验使用 scikit-learn 内置的 Wine 数据集，共包含：

- 178 个样本；
- 13 个理化特征；
- 3 个葡萄酒类别。

按照 80% : 20% 划分训练集和测试集，测试集包含 36 个样本。

## 实验结果

在 K=3 时：

| 数据处理方式 | Accuracy |
| --- | ---: |
| 原始数据 | 75.00% |
| 标准化数据 | 97.22% |

标准化使准确率提高了 **22.22 个百分点**，说明 KNN 对不同特征的数据尺度较为敏感。

进一步测试 K=1～20 后，K=7 是首次达到最高测试准确率的取值：

**Accuracy = 100.00%**

此时 36 个测试样本全部分类正确：

| 真实类别 / 预测类别 | class_0 | class_1 | class_2 |
| --- | ---: | ---: | ---: |
| class_0 | 12 | 0 | 0 |
| class_1 | 0 | 14 | 0 |
| class_2 | 0 | 0 | 10 |

使用相同的数据和参数进行 sklearn 对比实验：

| 实现方式 | Accuracy |
| --- | ---: |
| 手写 KNN | 100.00% |
| sklearn KNN | 100.00% |

两种方法的预测结果完全一致。

## 实验结论

本实验从零实现了 KNN 分类算法，并验证了欧氏距离、最近邻搜索和多数投票等核心步骤。

实验结果表明，特征尺度会明显影响 KNN 的距离计算。在 Wine 数据集上进行标准化后，K=3 时的测试准确率由 75.00% 提高至 97.22%。

不同 K 值也会影响模型的分类结果。本次数据划分下多个 K 值取得了 100% 的测试准确率，其中 K=7 是首次达到最高准确率的取值。

# Week 03：朴素贝叶斯文本分类

## 实验题目

**朴素贝叶斯文本分类——垃圾短信识别**

## 数据集

实验使用 **SMS Spam Collection** 数据集进行垃圾短信分类。

数据集共包含 **5572 条短信**：

| 类别 | 含义 | 样本数量 |
| --- | --- | ---: |
| ham | 正常短信 | 4825 |
| spam | 垃圾短信 | 747 |

数据集中正常短信数量明显多于垃圾短信，因此除了 Accuracy 外，本实验还结合 Precision、Recall、F1-score 和混淆矩阵评价模型性能。

## 实验内容

本实验主要完成：

1. 使用 `CountVectorizer` 将短信文本转换为词频向量；
2. 分析正常短信与垃圾短信中的词频特征；
3. 从零实现多项式朴素贝叶斯分类算法；
4. 计算类别先验概率；
5. 统计不同类别中的单词条件概率；
6. 分析朴素贝叶斯中的零概率问题；
7. 使用拉普拉斯平滑解决零概率问题；
8. 使用对数概率避免大量小概率相乘产生数值下溢；
9. 使用测试集评价手写朴素贝叶斯模型；
10. 与 sklearn `MultinomialNB` 进行对比。

## 文本特征提取

原始短信文本无法直接用于机器学习模型，因此实验使用词袋模型将文本转换为词频特征。

例如，假设词汇表为：

```text
["free", "win", "meeting"]
```

短信：

```text
free free win
```

可以表示为：

```text
[2, 1, 0]
```

表示 `free` 出现 2 次、`win` 出现 1 次、`meeting` 没有出现。

本实验使用 `CountVectorizer` 建立词汇表，训练集最终得到 **7668 个词特征**。

## 类别先验概率

训练集共有 4457 条短信，其中：

```text
ham：3859
spam：598
```

计算得到：

```text
P(ham)  = 0.8658
P(spam) = 0.1342
```

可以看出，在没有观察短信具体内容之前，一条短信属于正常短信的先验概率明显更高。

## 高频词分析

垃圾短信中出现次数较多的词包括：

```text
to
call
you
your
free
for
the
now
txt
ur
have
stop
text
claim
mobile
```

其中 `free`、`call`、`txt`、`claim`、`mobile` 等词具有较明显的垃圾短信特征。

正常短信中出现次数较多的词包括：

```text
you
to
the
in
and
my
me
is
it
that
of
for
so
have
but
can
are
your
on
not
```

同时可以发现，单纯出现频率较高并不意味着一个词一定具有较强的分类能力。例如 `you`、`to` 等词在两个类别中都较常见，因此朴素贝叶斯实际需要考虑单词在不同类别下的条件概率。

## 零概率问题与拉普拉斯平滑

实验发现：

```text
只在 spam 中出现的词：1621
只在 ham 中出现的词：5126
```

例如单词：

```text
00
```

在两个类别中的词频为：

```text
ham：0
spam：10
```

如果不进行平滑：

```text
P(00 | ham) = 0
```

一个条件概率为 0 可能导致朴素贝叶斯中的整个概率乘积变为 0，从而产生零概率问题。

加入拉普拉斯平滑后：

```text
P(00 | ham) = 1.739856635813209e-05
```

概率由 0 变为一个很小但非零的数值。

这一实验直观验证了拉普拉斯平滑能够有效缓解训练数据中未出现的“类别-特征”组合导致的零概率问题。

## 手写朴素贝叶斯实验结果

手写 Multinomial Naive Bayes 在测试集上的准确率为：

```text
Accuracy：98.74%
```

混淆矩阵：

| 真实类别 | 预测 ham | 预测 spam |
| --- | ---: | ---: |
| ham | 964 | 2 |
| spam | 12 | 137 |

分类报告：

| 类别 | Precision | Recall | F1-score | Support |
| --- | ---: | ---: | ---: | ---: |
| ham | 0.9877 | 0.9979 | 0.9928 | 966 |
| spam | 0.9856 | 0.9195 | 0.9514 | 149 |

模型仅将 **2 条正常短信错误识别为垃圾短信**，同时有 **12 条垃圾短信被错误识别为正常短信**。

虽然总体 Accuracy 达到了 98.74%，但由于数据集存在类别不平衡，因此还需要关注 spam 类别的 Recall。实验中 spam 的 Recall 为 0.9195，说明仍有少量垃圾短信未能被模型识别。

## 与 sklearn MultinomialNB 对比

使用相同的数据划分、词频特征和拉普拉斯平滑参数 `alpha=1.0`，进一步使用 sklearn `MultinomialNB` 进行实验。

结果如下：

| 模型 | Accuracy |
| --- | ---: |
| 手写 Multinomial Naive Bayes | 98.74% |
| sklearn MultinomialNB | 98.74% |

测试集预测结果比较：

```text
两种方法预测结果是否完全一致：True
```

在当前实验设置下，手写朴素贝叶斯与 sklearn `MultinomialNB` 的预测结果完全一致，验证了手写实现中先验概率计算、条件概率计算、拉普拉斯平滑以及对数概率分类过程的正确性。

## Week 03 实验总结

通过本次实验完成了从原始文本到垃圾短信分类的完整机器学习流程，并从零实现了多项式朴素贝叶斯算法。

本次实验主要掌握了：

- 多项式朴素贝叶斯；

- 拉普拉斯平滑；

# Week 04：线性回归

## 实验主题

**线性回归从零实现——基于加州住房数据的房价预测**

## 实验内容

本实验使用 California Housing 数据集完成房价预测任务，并使用 NumPy 从零实现基于梯度下降的多元线性回归模型。

主要完成以下内容：

1. 理解回归问题与分类问题的区别；
2. 理解一元和多元线性回归模型；
3. 使用 MSE 作为损失函数；
4. 理解并实现梯度下降算法；
5. 对输入特征进行标准化；
6. 从零实现多元线性回归模型；
7. 使用 MSE、RMSE 和 R² 评价模型；
8. 与 sklearn `LinearRegression` 进行对比实验。

## 数据集

本实验采用 sklearn 提供的 California Housing 数据集。

数据集共有 **20640 个样本**，每个样本包含 **8 个输入特征**：

- `MedInc`：收入中位数
- `HouseAge`：房龄中位数
- `AveRooms`：平均房间数
- `AveBedrms`：平均卧室数
- `Population`：人口数量
- `AveOccup`：平均居住人数
- `Latitude`：纬度
- `Longitude`：经度

预测目标为房屋价值中位数 `MedHouseVal`。

数据集中不存在缺失值。实验按照 8:2 的比例划分训练集和测试集，其中训练集包含 **16512 个样本**，测试集包含 **4128 个样本**。

## 特征标准化

由于不同输入特征的数值尺度存在较大差异，本实验使用 `StandardScaler` 对输入特征进行标准化。

标准化器只使用训练集进行拟合，再使用相同的均值和标准差转换训练集和测试集，从而避免测试集信息泄漏。

## 从零实现线性回归

本实验实现的多元线性回归模型为：

$$
\hat{y}=Xw+b
$$

使用均方误差 MSE 作为损失函数，并通过梯度下降不断更新权重 $w$ 和偏置 $b$。

实验设置：

- Learning Rate：`0.01`
- Epochs：`1000`
- Loss：MSE

训练过程中，MSE 从初始的 **5.6297** 下降至最终的 **0.5246**。Loss 曲线呈现先快速下降、后逐渐趋于稳定的趋势，说明梯度下降能够有效优化模型参数。

## 手写线性回归实验结果

手写模型在测试集上的结果：

| 指标 | 结果 |
| --- | ---: |
| MSE | 0.5546 |
| RMSE | 0.7447 |
| R² | 0.5768 |

训练集最终 MSE 与测试集 MSE 较为接近，没有出现明显的训练误差与测试误差差距过大的情况。

## sklearn 对比实验

使用 sklearn `LinearRegression` 在相同数据划分下进行对比：

| 模型 | MSE | RMSE | R² |
| --- | ---: | ---: | ---: |
| 手写 Linear Regression | **0.5546** | **0.7447** | **0.5768** |
| sklearn LinearRegression | 0.5559 | 0.7456 | 0.5758 |

两个模型预测值的平均绝对差异约为：

```text
0.0610
```

# Week 05：感知机

## 实验主题

**感知机从零实现——基于乳腺癌数据的二分类**

## 实验内容

本实验使用 Breast Cancer Wisconsin 数据集完成乳腺肿瘤二分类任务，并使用 NumPy 从零实现感知机（Perceptron）分类算法。

主要完成以下内容：

1. 理解感知机的基本原理与线性分类思想；
2. 理解感知机的误分类判断条件；
3. 掌握感知机权重和偏置的更新规则；
4. 将 `{0, 1}` 标签转换为 `{-1, +1}`；
5. 对输入特征进行标准化；
6. 使用 NumPy 从零实现感知机分类器；
7. 记录并分析训练过程中每轮的误分类次数；
8. 使用 Accuracy、混淆矩阵、Precision、Recall 和 F1-score 评价模型；
9. 与 sklearn `Perceptron` 进行对比实验。

## 数据集

本实验采用 sklearn 提供的 Breast Cancer Wisconsin 数据集。

数据集共有 **569 个样本**，每个样本包含 **30 个输入特征**，分类目标包括两个类别：

- `malignant`：恶性肿瘤
- `benign`：良性肿瘤

原始数据的类别分布为：

| 类别 | 样本数量 | 比例 |
| --- | ---: | ---: |
| malignant（恶性） | 212 | 37.26% |
| benign（良性） | 357 | 62.74% |

原始数据集使用 `0` 和 `1` 表示两个类别：

- `0`：malignant
- `1`：benign

由于经典感知机使用 `{-1, +1}` 作为类别标签，因此实验中将标签转换为：

- `-1`：malignant
- `+1`：benign

实验按照 8:2 的比例划分训练集和测试集，并采用分层抽样保持类别比例：

- 训练集：455 个样本
- 测试集：114 个样本

训练集类别分布：

- 恶性：170
- 良性：285

测试集类别分布：

- 恶性：42
- 良性：72

## 特征标准化

Breast Cancer Wisconsin 数据集中的不同特征具有不同的数值尺度。

例如，一些特征的数值可能达到数百甚至上千，而另一些特征的数值只有 0.1 左右。

感知机在遇到误分类样本时需要根据输入特征更新权重，因此不同的特征尺度可能影响参数更新过程。

本实验使用 `StandardScaler` 对输入特征进行标准化。

标准化器只使用训练集进行拟合，再使用相同的均值和标准差转换训练集和测试集，从而避免测试集信息泄漏。

标准化后，训练集各特征的均值约为 0，标准差约为 1。

## 感知机原理

感知机是一种**线性二分类模型**，其分类函数为：

**`f(x) = sign(w · x + b)`**

其中：

- **`w`**：权重向量；
- **`b`**：偏置；
- **`x`**：输入特征。

对于训练样本 **`(x_i, y_i)`**，如果满足：

**`y_i(w · x_i + b) <= 0`**

则说明该样本被**误分类**。

对于误分类样本，感知机按照以下规则更新模型参数：

**权重更新：**

**`w = w + η y_i x_i`**

**偏置更新：**

**`b = b + η y_i`**

其中 **`η`** 表示学习率。

本实验设置：

- **Learning Rate：`0.01`**
- **Epochs：`100`**

## 从零实现感知机

本实验使用 NumPy 从零实现感知机分类器。

模型首先将权重 $w$ 初始化为全 0 向量，并将偏置 $b$ 初始化为 0。

训练过程中依次遍历训练样本。当发现误分类样本时，根据感知机参数更新公式修改权重和偏置。

同时记录每轮训练过程中发生的误分类次数，用于观察模型的训练过程。

训练结束后得到：

```text
最终偏置 b：-0.04
```

前 10 轮误分类次数：

```text
[24, 12, 15, 16, 11, 11, 14, 8, 15, 14]
```

最后 10 轮误分类次数：

```text
[10, 12, 13, 9, 3, 13, 10, 7, 12, 12]
```

可以发现，每轮误分类次数并没有严格单调下降，并且训练结束时也没有下降到 0。

这是因为感知机在遇到误分类样本时会立即更新参数，一次参数更新可能改变其他样本的分类结果。同时，真实数据集也不一定严格线性可分，因此感知机并不一定能够找到一个将所有训练样本完全正确分类的线性超平面。

手写逻辑回归模型的交叉熵损失由初始的 0.6931 下降至 0.4531，说明梯度下降能够有效优化模型参数。

同时，本实验也说明，对于类别分布不完全均衡的分类任务，仅使用 Accuracy 不能全面反映模型性能，还需要结合 Precision、Recall 和 F1-score 等指标进行综合评价。
